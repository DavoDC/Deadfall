# Deadfall

A browser-based, first-person PVE extraction shooter set in a hostile jungle.
Insert, fight and explore through, gather resources under pressure, and reach
extraction before the jungle overwhelms you. Short self-contained runs. Warzone
DMZ energy, PVE only. Co-op planned.

Procedural and self-contained - no binary assets, no build step. Vanilla JS +
Three.js.

*Working title - built as a Fable 5 capability-ceiling experiment (2026-07-11).
See `docs/design.md` for the concept and `docs/fable-brief.md` for the build brief.*
